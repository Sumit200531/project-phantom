# Project Phantom

An original 3D tactical first-person shooter prototype built with **Godot 4.3 and GDScript**.
You and four bots fight five bots across *Helix Research Facility*. Attackers carry the
Phase Charge to site A or B. Defenders stop the plant or defuse it. First team to the
chosen round count wins, and the sides swap at halftime.

Everything in the project is original: the map, models, weapon designs, textures, shaders,
sounds and UI are generated by code in this repository. The only third-party files are two
fonts under the SIL Open Font License (see *Credits*).

---

## 1. Setup and launch

1. Install **Godot 4.3** (standard build, not .NET): <https://godotengine.org/download>.
   Godot 4.4 also works. Earlier 4.x versions are not supported.
2. Unzip the project and open Godot. In the Project Manager choose **Import**, then
   select `project.godot` in this folder and click **Import & Edit**.
3. The first open imports textures, sounds and fonts, which takes 10–30 seconds.
4. Press **F5** (Play) or the ▶ button. The main scene is `res://scenes/main.tscn`.
5. Wait for the menu to say **Facility ready.** The level and its navigation mesh build at
   startup, in about 1–2 seconds. Then click **PLAY**, pick your side, bot difficulty and
   match length, and click **DEPLOY**.

Command-line launch (after the first import):

```bash
godot --path /path/to/phantom                     # play
godot --path /path/to/phantom --import            # (re)import assets only
```

The renderer is **Forward+**. On machines without Vulkan, Godot 4.3 falls back to the
Compatibility renderer automatically. Some effects (SSAO, volumetric fog) are then skipped.

## 2. Controls

| Input | Action |
| --- | --- |
| W A S D | Move (acceleration-based, crisp counter-strafing) |
| Shift (hold) | Sprint (weapon lowers; firing cancels sprint) |
| Ctrl (hold) | Crouch (quiet footsteps, tighter spread; blocked under low ceilings) |
| Space | Jump (buffered, with coyote time) |
| Mouse | Look (raw input; optional smoothing in Settings) |
| Left mouse | Fire |
| Right mouse | Aim down sights (zoom, tighter spread, slower movement) |
| R | Reload (animated mag change; empty reloads also rack the bolt) |
| 1 / 2 / 3, mouse wheel | Lancet rifle / Hornet SMG / Kite sidearm |
| Q | **Shroud**: throw an obscuring field (blocks vision for 14 s) |
| E | **Aegis Wall**: energy barrier that stops enemy bullets (15 s, 750 HP) |
| C | **Echo Pulse**: reveals enemies within 28 m through walls for 4 s |
| F (hold) | Plant (4 s, inside a site) or defuse (7 s, half-way checkpoint) |
| Tab (hold) | Scoreboard |
| Esc | Pause (Resume, Settings, Restart, Quit) |

## 3. Gameplay summary

* **Rounds:** 12 s preparation behind spawn barriers, then a 1:45 round. The Phase Charge
  detonates 40 s after it is planted.
* **Win a round:** eliminate the other team, detonate the charge (attackers), defuse it or
  let the timer run out before a plant (defenders).
* **Damage:** hitscan with head, body and leg hit areas. Shields absorb 66 % of damage until
  depleted. The Lancet kills a fully shielded target with one headshot.
* **Weapons:** Lancet (auto rifle, learnable spray pattern), Hornet (SMG, accurate while
  moving), Kite (semi-auto sidearm). Spread grows with movement, jumping and sustained fire.
* **Abilities** have cooldowns shown on the HUD (radial sweep and seconds remaining).
* **Bots** see by distance, field of view and line of sight. Walls and Shroud fields block
  sight. They hear gunfire and running footsteps and share spotted enemies with their team.
  Attackers gather on a lane, execute onto a site with utility, plant and guard. Defenders
  hold angles, peek, rotate on intel, regroup, retake and defuse. In fights they react
  with a delay, aim with settling error, fire bursts, strafe and fall back to cover.

## 4. The map: Helix Research Facility

A 112 × 136 m facility with three attack lanes, flank tunnels and two distinct sites:

| Area | Identity |
| --- | --- |
| Freight Yard (attacker spawn) | Asphalt, shipping containers, cargo truck, warm sunlight, trees |
| A Main / B Main | Outdoor lanes: greenway planters vs. pipeline pipework; loading docks with stairs |
| **Site A: Hydroponics Lab** | White lab panels, green grow tanks, glass-roof greenhouse frame, raised deck |
| **Site B: Reactor Core** | Metal floors, cyan reactor landmark with a tall stack, generators, catwalk |
| Atrium (mid) | Grass courtyard, central tree, raised walkways on both sides, benches |
| Market | Stalls with awnings and string lights connecting yard and atrium |
| Server Hall / links | Roofed hall with server racks; A and B links to the sites |
| A / B Tunnels | Roofed flank corridors between the lanes and the atrium |
| Command Deck (defender spawn) | Teal command room with consoles and a holo table |

The geometry is modular and procedural. A 4 m cell layout drives the floors, walls,
roofs, platforms and ramps. Each wall face is decorated by area: windows, vents, pipes,
emissive strips, roll-up doors, screens and hazard bands. Props are placed by hand, and
draw calls are kept low by batching meshes per material and per 28 m chunk.

## 6. Architecture

* **Combatant** (`CharacterBody3D`) is the shared base of the player and bots. It holds
  team, `HealthComponent`, `Hitbox` areas (head/body/legs), `AbilityKit`, surface-aware
  footsteps, reveal state and stats.
* **Ballistics** resolves every shot with a physics ray. The ray mask includes world
  geometry, hitboxes and only the *opposing* team's barrier layer, which is how the Aegis
  Wall stops enemy bullets while allies shoot through it. Teammates' hitboxes are excluded,
  so there is no friendly fire.
* **PlayerController** handles input, acceleration movement, sprint, crouch, jump, landing
  springs and an interpolated camera with bob and tilt. **WeaponManager** handles firing,
  spread, recoil patterns, ADS, reloads, switching and the procedural first-person
  animation. The viewmodel renders in its own small world through an overlay viewport, so
  it never clips into walls and costs no extra shadow pass.
* **BotController** combines perception (FOV, line of sight, smoke, hearing, team intel), a
  decision layer per role and phase, and NavigationAgent3D movement with avoidance. It uses
  the same Ballistics, so bots hit only what their real rays hit. **BotModel** provides the
  procedural animated body.
* **MatchManager** runs phases (prep → live → planted → round end), round outcomes, the
  halftime side swap, statistics, team intel and sound events. It exposes static helpers
  such as `MatchManager.now()`. **ObjectiveDevice** runs carry, drop, pickup, plant,
  defuse and detonation.
* **FacilityBuilder** builds the level, lighting, reflection probes, spawn barriers,
  minimap image, tactical data (routes, holds, plant spots, cover points) and bakes the
  navigation mesh on a background thread at startup.
* **Autoloads:** `Settings` (persistent settings and graphics presets),
  `Sfx` (pooled 2D/3D audio), `Fx` (pooled tracers, impacts, decals, shells, lights, explosions).

### Collision layers

| Layer | Use |
| --- | --- |
| 1 World | Level geometry and props (navmesh source) |
| 2 Units | Character bodies |
| 3 Hitboxes | Head/body/leg areas queried by bullets |
| 4 / 5 Barrier team 0 / 1 | Aegis Walls (block the other team's bullets only) |
| 6 Spawn walls | Preparation-phase barriers |

## 7. Settings and performance

Settings are saved to `user://phantom_settings.cfg`.

* **Graphics presets:** Low, Medium, High, Ultra, plus individual toggles: render scale
  (FSR below 100 %), shadows (off/low/high), anti-aliasing (FXAA, MSAA 2×/4×), SSAO,
  bloom, volumetric fog, screen-space reflections, V-Sync, frame-rate cap, fullscreen,
  grass density.
* **Gameplay:** sensitivity, invert Y, mouse smoothing, FOV, camera bob, bot difficulty,
  crosshair colour, FPS counter.
* **Audio:** master, effects, ambience.

The first launch uses the **Medium** preset, which suits a modest PC; raise it to High or Ultra on a capable GPU. If the frame rate is low, lower **Render scale**
to 75–85 % and set **Shadows** to Low. Textures are 512 px, geometry is batched, and the
grass uses a MultiMesh with a distance cutoff.

## 8. Testing tools

```bash
# Headless bot-vs-bot match, logs every kill/plant/round, exits 0 on completion:
godot --headless --path . --fixed-fps 120 -- --autotest --rounds=5

# Movement checks: walk/sprint/crouch speeds, acceleration, stopping, jump height,
# stairs and ramps onto 2.4 m decks, wall collision, standing up under a roof:
godot --headless --path . --fixed-fps 120 -- --movetest

# Combat/objective checks: body-shot kill, one-tap headshot through shield, enemy barrier
# blocks bullets, own barrier lets them through, smoke blocks sight, plant, defuse checkpoint:
godot --headless --path . --fixed-fps 120 -- --combattest

# Scripted screenshots of every screen and mechanic (needs a display or Xvfb):
godot --path . -- --shots=/absolute/output/dir

# Regenerate textures and sounds (Python 3 with numpy, scipy, Pillow):
python3 tools/generate_textures.py
python3 tools/generate_audio.py
```

## 9. Troubleshooting

| Problem | Fix |
| --- | --- |
| "Facility ready" never appears | Check the Output panel for errors. The navmesh bakes on a thread and needs the default `navigation/3d` cell settings from `project.godot`. |
| Pink/missing textures or no sound | Assets were not imported. Reopen the editor, or run `godot --path . --import`. |
| Mouse does not turn the camera | Click inside the game window to capture the mouse. Esc releases it (pause). |
| Game pauses on its own | Losing window focus pauses the match on purpose. Click **Resume**. |
| Low frame rate | Use the Low/Medium preset, lower Render scale, disable Volumetric fog and SSR. |
| Vulkan errors on start | Launch with `--rendering-driver opengl3`, or update GPU drivers. |
| Bots stand still | They wait during the 12 s preparation phase; if it persists, the navmesh failed to bake (see first row). |
| Settings feel wrong after an update | Delete `user://phantom_settings.cfg` (Project → Open User Data Folder). |
